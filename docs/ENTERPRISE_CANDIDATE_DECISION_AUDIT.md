# 企业候选人决定审计

Copyright © 2026 上海如静知华信息科技有限公司 · <https://www.zhuatech.cn/>

`POST /api/enterprise/recruitai/candidate-decision-audit` 用于记录推进、录用和淘汰决定。接口核验岗位标准版本、逐项岗位证据、AI 使用告知、受保护属性排除、人工责任人、决定理由、评分卡、合理调整、申诉渠道及数据保留策略。

决策包括 `RECORDED / PANEL_REVIEW / HOLD / BLOCKED`。合理调整尚未处理时保持候选人状态；评分卡、申诉或保留策略不完整时进入招聘小组复核；受保护属性、非岗位相关评价、证据缺失或职责未分离会阻断状态变更。

响应生成稳定的 SHA-256 审计键和证据覆盖率。AI 只能提供候选排序或证据摘要，最终招聘决定必须由授权人员作出并允许候选人询问或申诉。
